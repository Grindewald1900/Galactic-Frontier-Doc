# 熵海协议：群星开拓

卡牌战斗 × 挂机采集 × 资源合成 × 玩家交易的原创星际开拓游戏设计项目。

## 核心循环

战斗解锁区域 → 挂机采集资源 → 加工与制造 → 强化卡组与装备 → 玩家市场交易 → 挑战新区域。
